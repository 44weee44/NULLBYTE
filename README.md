# NULLBYTE OS — v1.0.0

Одиночный мобильный симулятор хакерской жизни в виде личного виртуального компьютера. Реализация следует `SPECIFICATION.md`: пользователь работает с вымышленным миром, NPC, сайтами, виртуальными устройствами, игровыми плагинами, контрактами и внутренней экономикой.

> **Граница безопасности:** все IP, сайты, базы, банки, устройства, NPC, артефакты и действия полностью вымышлены. Игра не подключается к сторонним сайтам, не сканирует сети, не управляет реальными устройствами, не исполняет shell/SQL/JavaScript/Python и не собирает пароли, cookies, SMS или контакты.

## Запуск

Требуется Node.js 18 или новее. Все файлы находятся **в корне** — вложенных каталогов для JS, CSS и ресурсов нет.

```bash
npm start
```

Открой `http://localhost:8080`.

Проверка логики:

```bash
npm test
```

## Первый запуск и игровой цикл

1. Проходит загрузка NULLBYTE OS.
2. При первом запуске нужно создать ник: 2–12 латинских букв или цифр.
3. На рабочем столе доступны приложения: Профиль, Terminal, DarkShop, Browser, NULForge, NullAtlas, N-Mail, BlackWire, Help / Docs, NBS IDE, Aster Bank и My Computer.
4. Открой **BlackWire**, прими первый контракт.
5. Перейди в **Browser** к цели. Выполни цепочку: анализ → декодирование → обнаружение виртуального узла → поиск слабости → симуляция доступа → экспорт.
6. После создания файла результата открой **N-Mail** и отправь его заказчику.
7. После проверки начислятся кредиты и опыт; новые контракты и функции откроются с повышением уровня.

Начальный контракт доступен без покупки стартовых плагинов. Первые базовые пакеты уже установлены.

## Что реализовано

- Терминальная загрузка и onboarding с проверкой ника.
- Desktop/window manager: несколько окон, drag по заголовку, minimize, maximize/restore, close, переключение через taskbar, контроль доступной RAM.
- Адаптивный UI с поддержкой портретного и альбомного режимов, safe-area отступами, touch-friendly контролами и `prefers-reduced-motion`.
- Профиль: ник, справочный Telegram ID, уровень, XP, репутация, завершённые контракты и суммарный заработок.
- Компьютер: CPU, RAM, GPU, storage, уровни NULLBYTE OS, установка компонентов и контроль сохранности файлов.
- DarkShop: каталог и обновление комплектующих.
- NULForge: каталог игровых плагинов, цены, уровни, RAM/storage, установка и удаление без потери пользовательских файлов.
- Terminal: строго белый список команд `help`, `info`, `whoami`, `status`, `date`, `uptime`, `plugins`, `pkg list`, `plugin info NAME`, `ls`, `cat FILE`, `mission list`, `map`. Команды ОС не запускаются. Баланс в Terminal не показывается.
- Browser: только домены `.null`, поиск по собственному каталогу, вкладки, история и закладки. Нет переходов во внешний интернет.
- NullAtlas: вымышленный город, POI, точки целей и расписания NPC.
- BlackWire: 16 одиночных NPC-контрактов с последовательной прогрессией от первого заказа до уровня 10, лимит активных контрактов, награды и критерии.
- N-Mail: входящие/исходящие игровые сообщения, вложения, отправка результатов, автоматическая проверка с задержкой.
- Симуляция операций: плагины, требования, шанс, cooldown, усиление защиты при неудаче и восстановление цели по сохранённому timestamp.
- NBS IDE: редактор игровых деклараций, проверка синтаксиса, сохранение виртуальных файлов и запуск ограниченного интерпретатора с уровня 5.
- Aster Bank: только игровые кредиты и транзакции; динамическая оценка эндгейм-риска, конфискация и точная 24-часовая блокировка при виртуальной трассировке. Проверка награды учитывает момент завершения, даже если игрок вернулся после окончания таймера.
- Автоматическое сохранение и миграция известного профиля из старого ключа `nullbyte_player`.
- Тесты бизнес-логики и Telegram CloudStorage через Node.js test runner (`npm test`); синтаксическая проверка (`npm run check`).

## NBS — разрешённые декларации

```nbs
MISSION "job-001"
TARGET "volt-market"
ANALYZE target
DECODE artifact "sealed-record"
DISCOVER node
VERIFY requirement "weakness-found"
SIMULATE access
EXPORT dataset "job-001-result"
DELIVER mail "job-001"
```

Для виртуальной базы данных есть дополнительная команда `READ virtual-records`. Парсер принимает только точные строки из allowlist. Произвольный код, shell, SQL, сеть, `eval`, файловая система устройства и динамические импорты недоступны. NBS-файл — описание действий игрового движка, а не реальный скрипт атаки.

## Сохранения и Telegram Mini App

- В Telegram используется `Telegram.WebApp.CloudStorage`.
- CloudStorage ограничивает одно значение 4096 символами, поэтому игра сериализует сохранение в части по 3600 символов. Манифест с контрольной суммой записывается последним, чтобы незавершённая запись не считалась полной.
- В обычном браузере/локальной разработке используется `localStorage`.
- Схема сохранения имеет версию, выполняет миграцию и сохраняет прогресс, контракты, таймеры, состояние сайтов, NPC, файлы, плагины, банк и транзакции.
- `initDataUnsafe.user` используется только для справочного отображения имени/ID. Эти данные не являются подтверждённой авторизацией.

**Важно для публичного запуска:** это клиентский одиночный прототип. Локальные данные и время устройства пользователь может изменить. 24-часовая блокировка корректно сохраняется как timestamp, но не является защищённым серверным таймером. Для соревновательной/экономически значимой публикации нужен backend: серверная проверка `Telegram.WebApp.initData`, доверенные время и транзакции, серверная валидация миссий и защита от подделки CloudStorage/localStorage. В текущем проекте нет реальных платежей и внешних сетевых действий.

## Файлы проекта (все в корне)

- `index.html` — boot screen, рабочий стол, окно и modal shells.
- `style.css` — весь интерфейс и адаптивные стили.
- `app.js` — UI, окна и привязка событий приложений.
- `engine.js` — игровое состояние, экономика, мир, миссии, плагины, операции, NBS и конфигурация баланса.
- `storage.js` — Telegram CloudStorage, чанки, checksum, local fallback, migration.
- `engine.test.js` — автоматические проверки логики и прогрессии.
- `storage.test.js` — проверки CloudStorage, чанков и восстановления.
- `server.js` — локальный статический сервер без сторонних зависимостей.
- `manifest.json` — web app manifest.
- `nullbyte-mark.svg` — логотип NULLBYTE.
- `SPECIFICATION.md` — полное техническое задание проекта.
- `package.json` — команды запуска и тестов.

## Баланс

Тестовые цены, шансы, XP, требования, длительность cooldown, восстановление целей, лимит активных окон, банковский риск и награды вынесены в `engine.js` (`BALANCE`, `PLUGINS`, `HARDWARE`, `MISSION_TEMPLATES`). Значения помечены как черновые и требуют игрового тестирования.
